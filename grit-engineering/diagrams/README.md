# Diagrams

Mermaid sources. GitHub renders them inline when embedded in Markdown; the `.mmd` files are the editable sources.

| File | Shows |
|---|---|
| `module-dependencies.mmd` | Allowed package import edges (enforced by `scripts/check_layers.py`) |
| `data-flow.mmd` | Source data to model card |
| `experiment-state-machine.mmd` | Experiment lifecycle |
| `trust-boundaries.mmd` | Zones Z0 to Z7 and permitted crossings |
| `deployment-topology.mmd` | Profiles 1 to 4 |
| `prompt-dag.mmd` | Prompt dependency DAG (generated by `tools/build.py`) |
